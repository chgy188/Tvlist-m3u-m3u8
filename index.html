快速开始

IPTV 即通过 IP 网络传送电视内容。只要把播放列表地址粘贴到支持 M3U 的播放器即可观看。

1

挑一个播放列表

在下方「播放列表」中按地区或类型挑选，点击「复制」拿到地址。

2

粘贴到播放器

VLC / Kodi / IINA / nPlayer / GSE SMART IPTV 等都支持远程播放列表地址。

3

选择线路

组播 / RTSP 源通常需要在对应运营商网络内使用；全国源则无此限制。

插件安装的三种方式

  1. 搜索安装：打开 Kodi → 插件 → 左上角图标 → 搜索 → 找到插件安装，随后在「我的插件」中打开。
  2. 从 zip 安装：下载 zip 插件包（不要解压）→ 插件 → 从 zip 文件安装 → 先在设置中勾选「未知来源」→ 选择文件安装。
  3. 从插件库安装：先按方式二安装中文插件库（如 Chinese Add-ons、HDPfans 中文插件库）→ 插件 → 从库安装 → 选择分类安装。
